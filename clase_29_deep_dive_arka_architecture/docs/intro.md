Este sitio centraliza el deep dive de arquitectura del proyecto ARKA B2B.

## Que incluye

- Revision arquitectonica consolidada.
- Historias de usuario HU1 a HU8 con diagramas Mermaid.
- Extras de seguridad, pagos y reabastecimiento.
- Archivo fuente `drawio` para evolucion del diagrama base.

## Mermaid interactivo

Todos los diagramas Mermaid tienen controles de:

- Zoom in y zoom out.
- Pan con drag.
- Reset de vista.
- Pantalla completa para diagramas grandes.

## Draw.io base

Puedes abrir la referencia del diagrama base desde la pagina `Draw.io Base` en el sidebar o directamente en `drawio-referencia`.
